# Stochastic Challenges (CoRL 2026) project page

Static site, no build step. `index.html` + `assets/`.

## Publish with GitHub Pages
1. Create a repo (e.g. `rpl-bonn/stochastic-challenges`, or `<your-user>/stochastic-challenges`).
2. Copy the contents of this folder to the repo root and push to `main`.
3. Settings > Pages > Deploy from branch > `main` / root.
   Site appears at `https://rpl-bonn.github.io/stochastic-challenges/`.
